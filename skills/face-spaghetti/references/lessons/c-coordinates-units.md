# C. 坐标系与单位

| 症状 | 机制 | 规则 |
|---|---|---|
| 「坐标/比例算出来挺合理」 | 被测进程 DPI-unaware，被系统放大；抓图是物理像素、被测逻辑是另一套尺寸 | 单位与坐标系写进仪器用法；比例按**抓图尺寸**算；DPI 感知先 `SetProcessDpiAwarenessContext(-4)` |
| 「按世界坐标算出的点落在箱框/空白上」 | 屏幕 y 与 GL/世界 y 反向；视口 top/bottom 不是设计空间 | 标定图里画已知世界点+鼠标位置；标注点不压住实际对象先改映射，不发输入 |
| 「覆盖率报 95%，库层已收敛」 | 分子在候选坐标系、分母在目标坐标系 | 跨坐标系计数写清分子/分母 + 一个**会崩的对照**（放到不可能匹配的位置应掉到 0） |
| 「窗口 rect 两侧差 20 px，客户区与控件逐字段全对」 | 两侧 NC 区不同（菜单栏 / 边框）；公式给的是客户区尺寸，`GetWindowRect` 含 NC | 等式判据落客户区与内部布局；NC 差记宿主特性；resize 先按目标 client 迭代校正（I39） |
