# F. 环境与替身

| 症状 | 机制 | 规则 |
|---|---|---|
| 「放进私有桌面/新会话就隔离干净了」 | 私有桌面只隔离窗口与输入；音频端点、系统混音器、存档/配置仍是同一会话的共享资源 | 逐维列隔离面（输入/显示/音频/存储/网络）并各给一条读数对照；共享资源要么隔离（独立 profile、虚拟音频设备），要么备份-恢复；「没抢前台」不等于「没副作用」 |
| 「私有桌面截图成功，图却是黑的」 | 私有桌面隔离窗口/输入，但 GL 前端缓冲不走 GDI/`PrintWindow`；返回 1 不证明抓到像素 | 完成判据用产品侧状态标记（回调里 teleport/创建/字段），像素只在默认桌面作验收（instruments I29/I30） |
| 「第二个实例迟迟不出窗」 | 单实例限制；测到的是残留状态 | 探测前清残留实例/占用；单实例行为本身记 `待证` |
| 「环回录音自比，相关系数低得可疑」 | 别的进程占着声卡 | 独占设备先确认空闲 |
| 「自建那份和原版一样，能当参照了」 | 替身的等价性要另证 | 先过可观测面门禁：可观测量逐字段 `diffs=0` 之后才有资格当对照 |
| 「差异只剩一点点，记成已知偏差收工」 | 非代码输入也能改行为（PE 子系统版本、manifest、DPI 上下文） | 先追非代码输入再改代码：子系统版本过低会触发旧式非客户区度量 |
| 「A/B 里被测程序不退出 / 注册表被写脏 / 机器响了一声 / 自投递把 A/B 窗口关掉」 | 仪器 hook 未按测量窗口门控：无条件吞掉 `PostQuitMessage` 让进程永不退出；缺开关时注册表调用漏到真实 HKCU；默认音频端点被真实播放；`SendMessageW(WM_CLOSE)` 同步自投递真派发销毁 A/B 窗口 | 每个 hook 默认**转发真 API**，只在测量窗口内拦截；开关逐 pass 复位、结束后恢复原值；音频 / 关窗类调用在窗口内记录后吞掉，真实效果单列 `UNMEASURED`；自证含「进程退出码与真实运行一致」「连跑两次 A/A=0」 |
| 「gate 的 `reg export` 突然报「无法写文件」」 | 另一条 GUI 判据同时在删/恢复同一个 HKCU 键——两个仪器共享同一注册表键，并行时互相踩 | 共享同一资源（注册表键/音频端点/光标/单实例/窗口）的仪器**串行**跑；并行只允许只读或资源不重叠。失败先查并发，再把「串行 + 重试」写进用法；日志保留两端 start/restore 时间 |
| 「文档里的判据命令照抄，直接 `ModuleNotFoundError` / 解析器不对」 | 判据命令的解释器与依赖也是仪器的一部分：`uv run` 的隔离环境与系统解释器不是同一套包，缺依赖时判据不是「红」而是「不可用」 | 判据行 / 工具 docstring 写明解释器与额外依赖（例：gate 需要 numpy ⇒ 用系统 `python`）；换环境先跑一次那条文档命令；依赖缺失按仪器不可用处理，不写进被测结论 |
| 「进程退出时写的日志文件是 0 字节」 | 事件在退出路径 flush；探针先 `taskkill` 再读文件，读到的是未落盘的尾巴 | 动作前先开进程句柄，等真实退出（`GetExitCodeProcess`）再读；空文件先判「杀早了」，别记成宿主缺陷 |
| 「两侧控件 rect 差 1px，代码怎么都对不上」 | 测量子进程 DPI-unaware，跨进程读窗口 rect 被 DPI 虚拟化；physical px 与 virtual px 混用 | 几何判据固定测量进程 DPI awareness（PER_MONITOR_AWARE_V2）并声明物理像素；系统性 1px 先当测量伪影，改探针再说 |
| 「新加的 hook 环恒为空，产品明明调用了这个 API」/「换了同族的另一个函数，环里全是另一个 fn」 | IAT hook 对**未导入**的 API 静默不装；产品走的是同族的另一个函数（如 `TextOutW` vs `DrawTextW`） | 暴露 installed 位并在 lane 先断言「该装的都装了」；hook 表与导入表交叉核对（I44） |
