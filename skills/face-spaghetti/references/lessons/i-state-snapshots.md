# I. 状态迁移与快照

| 症状 | 机制 | 规则 |
|---|---|---|
| 「实现比 oracle 多回 / 少回一步」/「flip 后 undo 还回退了动作」 | Undo 深度与历史语义是行为，不是实现细节：单层栈、flip 清空、哪些动作可撤销都要实测；按「自然实现」写多层栈会多回一步 | 先跑第二次 undo（以及 flip / 发牌前后的 undo），用 oracle 固定每步 digest / score；host 与 oracle 同结果才收口；负例用能多回一步的 mutant |
| 「函数升级后普查桶还是旧数」 | 普查在状态落盘前跑；旧快照的桶数 / 哈希已过期 | 状态变化后重跑普查；旧快照置 `过期`，写错的旧行 `已证伪` + 删除线 + 勘误快照；不手改数字（claims.md 快照行） |
| 「宿主行为修好了，函数状态也该跟着升级」 | 函数级 A/B 与宿主行为行是两套证据；宿主通过不证明函数定义域已覆盖 | 宿主行为行（如 `host:*`）与函数状态分开记；`integration` 不替代 canned A/B；替换 stub 并重跑同一 A/B 才升 `已证`（claims.md 台账粒度） |
| 「快照只多两个字段，旧 digest 应该还能比」 | 序列化区一改，既有 digest 全部失效；版本常量在一端硬编码时两端各说各话 | schema 变更 = 版本号 + 区表 + 两端常量 + 回复字段一起改；旧录制标过期并重录；digest 只在同版本内可比，缺失区不得用近似顶替 |
| 「没测全就标 `已证`，测过几条就升格」 | 实现缺口（有实现、证据不足）与证据缺口（有证据、仍有未测 / stub 维度）是两种东西；用「已证」盖住会同时丢掉缺口与回流条件 | 状态按证据形状定；降级与恢复都追加勘误行，不覆盖旧结论；回流条件逐项进 backlog |
| 「判据命令指向 `work/` 里的脚本，或命令已不存在」/「换了个同名语料，`aa=2`，以为是本批回归」 | `work/` 是 gitignored 一次性目录；命令漂移让「历史通过」无法复现；判据行登记的是另一份语料（`foo_live.jsonl`），临时导出的红不是回归 | 判据只指向 tracked 的永久仪器目录，语料写来源 + 指纹；红先核对是否就是登记的那份，再到干净 HEAD 的 worktree 复跑，两者都红才按本批处理（SKILL §2.4） |
| 「callee 是 `已证`，调用方按它的分支算覆盖就行」 | `已证` 只覆盖语料走到的分支；调用方进到未测分支时，callee 的结论不适用 | 调用方进未测分支 ⇒ 调用方 `blocked`；callee 的 spec 列出未测分支与回流条件（SKILL §5） |
| 「这个函数 15/15 `已证`，用户说功能根本没有」/「宿主把已对齐函数的归一化重写了一份，点空白把对象移丢了」 | `已证` 只锁 S 与该函数等价；宿主 WndProc / 消息表 / 资源没接线时功能从未生效；另写一份 = 第三个实现，只有一份有 A/B | 宿主接线（消息 / 菜单 / 光标 / 资源 / CLI）是独立判据；能调 S 就调 S，必须重写时按 `partial` 记并给重写自己的 A/B（SKILL §5） |
| 「台账命令里带开局参数，我跑的时候省了，反正 ctx 从 live 取」 | 未 settle 的 live 状态（初始化动画 / timer）会让 A/B 挂在固定 seq、进程单线程 100% CPU、控制通道不再应答 | 命令里的初始化参数是判据的一部分，照抄执行；省掉做对照，把挂起率写进台账（I35） |
| 「换目标 exe 跑清单工具，第一秒就 baseline mismatch」 | 工具把上一个目标的 md5 / entry RVA / 节范围写死当校验 | 目标元数据可配置（`--baseline` 或自动探测），硬编码只作默认值；换目标先跑一次清单生成（SKILL §2.4） |
| 「手工修补快照后写回报 CRC / 字段不符」 | 容器 payload 偏移不是文件头之后，而是「头 + 区表」；整体 CRC 与 region CRC 覆盖范围不同；恢复后还可能被 refresh / derived 覆盖 | 按格式文档算偏移并重算两级 CRC；用恢复端自带工具写入，写后读回校验 |
| 「ctx 结构加了字段，旧语料照跑」 | 结构、packer、元数据 `ctx_len` 三处不同步；工具在发送前就可能拒绝或用错长度 | 结构变更同批改生成器 + `ctx_len`，先跑 `--check`（逐字节）；旧语料按失效处理（SKILL §2.4） |
| 「外部 DLL 测不了，所以 wrapper 只能 `partial`」 | wrapper 的合同是调用序 / 参数 / 返回转发；B 的内容不是 A 的可观测面 | 计划替身只替换 B 的返回值时，A 的调用环可完整判据、可升 `已证`；B 的内容单列 `UNMEASURED`（`claims.md` Wrapper 例外） |
| 「状态 digest 两侧相等，像素却差一整块」 | 派生视觉状态（被排除的全局，如图标 cache）不在快照里，却决定绘制；`set_state` 只恢复快照域 | 派生量按**实测迁移**建模并单列（新局=2、赢局某全局清零=0、hover 有对象=3）；快照相等只授权状态面，像素面另立判据/定义域行；未测的迁移（基础 mode 2 / 派生 mode 4）进 backlog，不拿状态 digest 顶替 |
