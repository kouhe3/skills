# 设计来源

- Schein：过程咨询、谦逊的问讯；问在答前，客户拥有问题。
- Danganronpa 1：claim / weak spot / evidence 的形式；但它是预装弹夹，弱点是高亮的。
- 魔裁 Act01：操作与证据分槽、`Clue`/`Profile` 整池、错误操作仍要举证；但它有 `CorrectEvidenceId`、`Damage`、计时和强制投票。
- 魔裁 Act02（二周目，希罗）：主角开局被关押，没有调查段，审判庭只能靠逻辑否定、伪证探针、拿别人的证词互相抵消；终盘（10-13 之后）不再是凶案，而是把同伴从魔女化里劝回来，即价值之争，证据失效。
- 986 个判定段落的操作命中率：指摘 25%、赞同 16%、提问 3%、伪证 36%、魔法 46%。赞同的 14 个 ⭕ 全是同一形态——接受对方结论再反用。
- 本 skill 取结构：操作 → 证据 → status；不取答案键、预置菜单、惩罚，也不取“提问是输的动作”作为普适规则——它只在对方有动机隐藏时成立。
